# Tutorial para App Móvil II

Tutorial para el desarrollo y publicación de una aplicación móvil para Android e iOS, utilizando **React Native con TypeScript y TSX** para el frontend, un backend desarrollado en **Python** y una base de datos **PostgreSQL**, con despliegue de servicios en **Google Cloud Run**. La aplicación incorpora un sistema de inicio de sesión mediante autenticación con cuentas de Google, gestión de usuarios, solicitudes y permisos de acceso a un catálogo de 24 modelos de cálculo, identificados mediante IDs únicos. Asimismo, el tutorial aborda la integración entre la aplicación móvil, el backend y la base de datos, la administración del repositorio público mediante GitHub y la configuración de servicios en Google Cloud, sin utilizar Firebase ni WebView.
